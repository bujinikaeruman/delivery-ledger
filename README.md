# フーデリ採算くん

フードデリバリーの案件を**受注前に判定**し、実績で振り返るアプリです。
スマホのブラウザだけで動きます。インストール不要・登録不要・無料。

## → https://bujinikaeruman.github.io/delivery-ledger/

紹介ページ: https://bujinikaeruman.github.io/delivery-ledger/lp/

## できること

- **ワンタップ記録** … 走行中はボタンを押すだけ。数字は入れません。相乗せ（PPDD・PDD・PPDDD）もそのまま記録できます
- **判定** … 報酬と距離を入れると「受ける／条件付き／見送る」を表示。その店の過去の店待ち実績も出ます
- **釣銭計算** … 代引きの商品代金を入れると、出されそうな金額とお釣り・硬貨の内訳を一覧表示
- **収支** … クエストの進捗と支出。日次・月次の実質手取り
- **分析** … 今週と先週の比較、サービス別・店舗別・時間帯別・建物種別

## 使いはじめ

1. 上のURLをスマホで開く
2. ブラウザのメニューから **「ホーム画面に追加」**（アプリのように起動でき、圏外でも動きます）
3. 設定(⚙)で自分の目標ライン（円/時・円/km）を決める

## データについて

- 記録はすべて**自分の端末の中だけ**に保存されます。ログイン不要、外部への送信はありません
- **ブラウザの履歴やサイトデータを消すと記録も消えます**。ときどき設定からJSONで書き出してください
- 機種変更のときは、旧端末で書き出したJSONを新端末で読み込めば移せます

## AI機能について（任意）

「スクショから案件を即判定」と「お知らせの要約」は、Google の Gemini APIキーを自分で登録した人だけ使えます。
設定(⚙)のAPIキー欄が空のあいだは、これらのボタンは表示されません。**それ以外の機能はすべてキーなしで動きます。**

キーは aistudio.google.com/apikey から無料で取得できます。
